# Портал учёта производственных простоев ОМК-ИТ

## Описание проекта

Веб-портал для автоматизации учёта производственных простоев по вине ОМК-ИТ. Заменяет ручной процесс копирования данных из СААРЦ в Excel, ведения Word-документов с хронологиями и разборами инцидентов, и формирования отчётов для руководства.

## Текущий статус

**Этап 1 (текущий):** Разработка на тестовом Windows-компьютере в WSL2 (Ubuntu). Источник данных — вымышленные данные, генерируемые скриптом. База данных — SQLite.

**Этап 2 (будущий):** Переезд на корпоративный сервер Oracle Linux. Источник данных — реальная БД СААРЦ через SQL-запросы (без парсинга веб-страниц).

## Детальная спецификация отчёта

### Служба ДИТ (фиксированная)

Отчёт строится вокруг службы **ДИТ** (Департамент информационных технологий). Эта служба фиксирована:
- Отображается как информационная плашка в шапке отчёта
- Не может быть изменена через интерфейс
- Все данные в отчёте относятся только к этой службе

### Фильтры отчёта

| Фильтр | Тип | Обязательность | Описание |
|--------|-----|----------------|----------|
| Дата от | Дата | Обязательно | Начало диапазона |
| Дата до | Дата | Обязательно | Конец диапазона |
| Цех | Select | Необязательно | Из справочника (см. ниже) |
| Участок | Select | Необязательно | Из данных (динамический) |
| Статус | Select | Необязательно | Новый / В работе / Решён / Вне зоны ОМК-ИТ |

**Кнопки:**
- Применить — применить фильтры
- Сбросить — очистить все фильтры
- Экспорт в Excel — выгрузить текущий список в .xlsx

### Справочник цехов

Цеха приходят из источника в полном формате, например:
- `АО "ВМЗ" - ТЭСЦ-1`
- `ВлФ "МК ОМК-ЭкоМеталл" - Вязники`
- `ООО "ВМЗ-Техно" - КРЦ`

**Для отображения в фильтре** используется короткое название:
- ТЭСЦ-1, ТЭСЦ-2, ТЭСЦ-3, ТЭСЦ-4, ТЭСЦ-5
- МКС-5000
- КПЦ ДЖДК, СПЦ ДЖДК
- ЛПК, ТПЦ
- Спецтехника
- ЦАПТ, ЦЗЛ, ЦПМ
- ВМЗ-Техно КРЦ, ВМЗ-Техно МРЦ
- Эколант ЭМК
- филиалы МК ОМК-ЭкоМеталл

**В базе данных** хранится полное название. Преобразование полное ↔ короткое делается на уровне отображения.

### Разбор инцидента

Структурированный документ, привязанный к сводному простому.

**Составные части:**

1. **Шапка:**
   - Номер разбора

   - Корневые (список)
   - Сопутствующие (список)

5. **Принятые меры** — список

6. **Таблица запланированных мероприятий:**

### Группировка данных

При загрузке из источника данные группируются в сводные простои.

**Режимы группировки:**

1. **По цехам за период**
   - Один сводный простой на каждый цех за весь выбранный диапазон
   - Ключ группировки: `цех + название простоя`
   - Разные названия создают разные сводные записи

2. **Все в один простой**
   - Все цеха и дни объединяются в один сводный простой
   - Используется для общего обзора

**Логика:**
```typescript
function groupDowntimes(
  records: DowntimeRecord[],
  mode: 'by-shop-period' | 'all-in-one'
): ConsolidatedDowntime[] {
  if (mode === 'all-in-one') {
    // Все записи в один сводный простой
    return [{
      id: generateId(),
      title: 'Сводный простой',
      records: records,
      // ...
    }];
  }
  
  // По цехам: группируем по (цех + название)
  const groups = groupBy(records, r => `${r.shop}|${r.title || 'Сводный простой'}`);
  return Object.entries(groups).map(([key, records]) => ({
    id: generateId(),
    title: key.split('|')[1],
    shop: key.split('|')[0],
    records: records,
    // ...
  }));
}
```

## Функциональные модули

### 1. Учёт простоев
- Загрузка записей из источника данных
- Автоматическая группировка по дате/цеху/участку
- Режимы группировки: по цехам за период ИЛИ все в один простой

### 2. Список сводных простоев
- Таблица с фильтрами (дата, цех, участок, статус)
- Сортировка по любому столбцу
- Массовые операции: объединение, удаление (только для админа)

### 3. Страница простоя
- Вкладки: Общая информация, Разбор инцидента, Чат, Файлы, История, Детализация
- Детализация: просмотр/редактирование/удаление исходных строк

### 4. Разбор инцидента
- Структурированный документ с полями
- Экспорт в .docx (Times New Roman, шапка, таблицы)

### 5. Мероприятия
- CRUD внутри разбора
- Статусы: выполнено / не выполнено / просрочено

### 6. Хронология событий
- Записи время + событие
- Даты-разделители

### 7. Чат и уведомления
- Внутрисистемный чат
- Колокольчик с счётчиком непрочитанных
- Типы уведомлений: комментарии, статус, добавление, файлы, разбор

### 8. Управление доступом
- 3 роли: пользователь, ответственный, администратор
- Профили пользователей
- Управление участниками (только админ)

### 9. Аутентификация
- Логин/пароль (хэши)
- Будущая интеграция с доменной аутентификацией

### 10. Файлы
- Прикрепление к простою
- Хранение на диске, метаданные в БД
- Предпросмотр изображений и PDF

### 11. Экспорт
- Детализация → Excel
- Разбор → Word (.docx)

### 12. Аудит
- Лог всех значимых действий
- Фильтры: дата, пользователь, тип действия

### 13. Темы
- Светлая и тёмная тема
- Переключатель в шапке
